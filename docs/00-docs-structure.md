# docs 目录文件结构规划

## 命名规则

- **格式**：`<序号>-<描述>.md`
- **序号**：两位数字，从 `01` 开始，按创建/变更时间顺序递增
- **描述**：简短英文或拼音，描述文档内容

## 维护原则

1. **新增文档**：使用下一个可用序号（如当前最大是 02，新文档用 03）
2. **重命名现有文档**：若需调整顺序，统一重命名并更新本表
3. **文档内容**：每个文档应包含创建/更新时间、变更说明、相关 commit 等信息
